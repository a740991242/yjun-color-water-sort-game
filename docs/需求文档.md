# 魔彩瓶需求文档

## 1. 项目概述

魔彩瓶是一款面向移动端优先体验的颜色倒水闯关小游戏。玩家通过选择瓶子并倒水，将相同颜色的水整理到同一个瓶子中完成关卡。

项目目标是做一个有辨识度的休闲益智小游戏，核心体验包括：

- 玩法简单直观，儿童和普通用户都能快速理解。
- 视觉风格明亮、可爱、偏魔性，符合“魔彩瓶”命名。
- 支持简单模式和困难模式，形成递进挑战。
- 兼顾娱乐和轻教育，支持中英文教学朗读。
- 能部署到 GitHub Pages，用户通过浏览器直接访问。

## 2. 目标用户

- 喜欢颜色整理、倒水排序类小游戏的休闲玩家。
- 儿童及亲子场景用户，需要简单反馈和双语提示。
- 分享给朋友试玩的移动端 H5 用户。

## 3. 使用场景

- 手机浏览器打开链接直接游玩。
- PC 浏览器打开链接试玩或调试。
- 家长打开教学朗读，让孩子跟随中文、英文或双语提示学习颜色和动作表达。
- 开发者在本地调整关卡、音效、视觉资源后部署到 GitHub Pages。

## 4. 核心玩法需求

### 4.1 基础规则

- 一个瓶子可容纳固定层数颜色水，默认容量为 4。
- 玩家先点击一个有水的瓶子，再点击目标瓶子完成倒水。
- 只允许倒入空瓶，或倒入顶部颜色相同的瓶子。
- 目标瓶子满时不能继续倒入。
- 空瓶不能作为倒出来源。
- 每次有效倒水计 1 步。
- 所有非空瓶都被同一种颜色填满，且瓶子容量满足关卡要求时，判定通关。

### 4.2 关卡模式

- 简单模式：作为当前基础模式，适合快速上手，关卡默认开放。
- 困难模式：作为进阶挑战，包含更多瓶子、限时、特殊容量或特殊瓶机制。

### 4.3 特色关卡机制

- 空瓶：给玩家提供临时中转空间。
- 分层液体：瓶内颜色分布复杂，需要规划步骤。
- 限时关卡：在规定时间内完成，否则失败。
- 特殊容量瓶：部分关卡瓶子容量不是默认 4。
- 只接水瓶：只能作为目标瓶，不能作为倒出来源。
- 只倒出瓶：只能作为来源瓶，不能作为接收目标。

## 5. 交互需求

### 5.1 主界面

- 顶部展示当前模式和关卡，例如“简单 1”“困难 5”。
- 顶部标题展示“请将相同颜色的水倒在一起”。
- 顶部信息区展示步数、时间状态、关卡标签，要求一行展示。
- 中间 Canvas 展示瓶子、水层、背景元素和动画。
- 底部操作区展示撤销、提示、重开、音乐、音效。
- 右上角设置按钮使用齿轮图标。

### 5.2 设置面板

设置面板覆盖当前游戏页面，包含三个分类：

- 关卡：模式切换、关卡选择。
- 声音：背景音乐、倒水音效、总音量、音乐音量、音效音量。
- 教学：教学朗读开关、语音音量、幼宝/常规模式、中文/英文/双语。

设置面板要求：

- 移动端高度占满一屏。
- 关闭按钮不换行。
- 当前选项使用粉色高亮，普通选项使用浅蓝色。

### 5.3 操作反馈

- 点击有水瓶子时显示选中状态，并播放拿起音效。
- 再点同一瓶子时取消选中，并播放放下音效。
- 倒水时展示瓶子倾斜、水流、目标瓶水位上涨动画。
- 无效操作时瓶子抖动并提示原因。
- 通关时展示结果面板、星级和最佳步数。
- 非最后一关通关后自动进入下一关。
- 最后一关通关时隐藏瓶子，展示彩虹桥、持续撒花和恭喜通关效果。

## 6. 视觉需求

- 整体风格：粉色背景、天蓝底部水面、简约扁平玻璃瓶。
- 瓶子：白色边框、玻璃质感、高光、轻阴影。
- 水层：高饱和颜色，层与层之间有轻微分隔。
- 封面：首次进入展示完整封面图，手机使用竖版图，PC 使用横版图。
- 封面动画：至少展示 1.8 秒，再以拉开动画进入游戏。
- 彩虹桥：最后通关展示更醒目的彩虹桥和撒花。

## 7. 音频需求

### 7.1 背景音乐

- 默认关闭，不记录“音乐开”状态，避免刷新后自动播放失败。
- 用户点击音乐按钮后播放。
- 手机端需要兼容 iOS Safari、iOS Chrome、微信内置浏览器的播放限制。
- 使用 m4a 优先、mp3 兜底。

### 7.2 倒水音效

- 用户开启音效后，倒水时播放真实倒水/咕嘟声。
- 倒水音效应比背景音乐更明显。
- 倒水音效播放时可以适当压低背景音乐音量。

### 7.3 UI 操作音效

- 拿起瓶子：轻柔木块点按声。
- 放下瓶子：较低、更稳的短促放下声。
- 错误、提示、通关可使用短促合成音作为反馈。

### 7.4 教学语音

- 教学朗读与教学提示合并成一个开关。
- 支持中文、英文、双语。
- 支持幼宝模式和常规模式。
- 幼宝模式用更短句，例如颜色类提示更简短。
- 语气应偏温柔妈妈风格，避免每句都带“宝贝”“小朋友”等称呼。

## 8. 数据与存储需求

使用浏览器本地存储记录：

- 当前模式。
- 当前关卡。
- 音效开关。
- 教学开关。
- 教学语言和模式。
- 音量设置。
- 最高星级和最佳步数。
- 困难模式解锁进度。

不记录背景音乐开关状态，避免刷新后浏览器拦截自动播放。

## 10. 非功能需求

- 移动端优先，兼容 iOS Safari、iOS Chrome、微信内置浏览器。
- 首屏布局不需要刷新即可适配。
- 设置按钮、底部操作按钮、标题和信息 chip 不应重叠或换行异常。
- Canvas 动画保持流畅。
- 音频失败时不要阻塞游戏操作。
- 资源体积可控，图片和音频资源按需加载。
- 不依赖外部开源游戏项目代码，核心倒水逻辑自研。

## 11. 当前已知风险

- iOS 浏览器对多音频播放有严格限制，背景音乐、短音效、教学语音不能假设一定能同时在同一次手势内启动。
- Maestro 可验证 UI 状态，但不能替代真实听感测试。
- 部分 Maestro 文案断言受浏览器缓存状态影响，需要定期维护测试脚本。

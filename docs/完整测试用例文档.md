# 魔彩瓶完整测试用例文档

## 1. 测试目标

验证魔彩瓶在 PC 和移动端浏览器中的核心体验稳定可用，包括：

- 首屏封面和响应式布局。
- 颜色倒水核心规则。
- 简单模式和困难模式。
- 设置面板。
- 背景音乐、倒水音效、拿起/放下音效、教学语音。
- 教学模式。
- 通关、最终通关和彩虹桥撒花。
- GitHub Pages 部署后线上访问。

## 2. 测试环境

### 2.1 本地开发环境

- macOS。
- Node.js 满足 `package.json` engines。
- pnpm 9+。
- Vite dev server。

启动命令：

```bash
pnpm dev -- --host 0.0.0.0 --port 5201
```

本地地址：

```text
http://localhost:5201/
```

### 2.2 浏览器环境

需要覆盖：

- macOS Chrome。
- macOS Safari。
- iOS Safari 真机。
- iOS Chrome 真机。
- 微信内置浏览器，如需要分享测试。

### 2.3 自动化环境

Maestro iOS Simulator：

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk PATH=/opt/homebrew/opt/openjdk/bin:$PATH maestro test --device 5D638AC4-9707-4415-80E7-DB65C0305D61 .maestro/ios-safari-audio-debug.yaml
```

## 14. 自动化测试用例

当前 Maestro 脚本：

- `.maestro/ios-smoke.yaml`
- `.maestro/ios-audio-debug.yaml`
- `.maestro/ios-safari-smoke.yaml`
- `.maestro/ios-safari-audio-debug.yaml`

建议维护策略：

- smoke 脚本验证关键按钮可见。
- audio-debug 脚本验证调试条状态变化。
- 不要把 `SFX: off` 或 `SFX: on` 写死，除非脚本先清理浏览器状态。
- 音频真实听感仍需真机人工确认。

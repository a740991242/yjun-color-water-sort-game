# 魔彩瓶

一款用原生 HTML Canvas 实现的颜色倒水闯关小游戏。

## 运行方式

直接用浏览器打开 `index.html` 即可运行，不需要安装依赖或启动构建工具。也可以部署到 GitHub Pages、Vercel、Netlify 等静态托管服务。

## 当前功能

- 从零实现 Canvas 颜色倒水逻辑。
- 简约扁平玻璃瓶、透明边框、高光和自定义液体配色。
- 支持点击选瓶、倒水、撤销、重开、下一关。
- 内置经典、分层、窄口瓶、特殊瓶、限时关卡。
- 倒水音效优先使用 `assets/pour-water.mp3`；加载失败时回退到 Web Audio API 合成音效。
